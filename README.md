I wrote the requirements spec, helped design the database, and owned the UI and the React/TypeScript frontend, including the maker-checker screens where a reviewer can flag individual fields for the person who entered them. I now lead the ERP's UI redesign and its design system. The code is private.

My final-year project is automatic scaling of ionosonde ionograms. I built a dataset of 288,740 hourly ionograms from four NICT stations (2016-2024) and reimplemented four published autoscalers to compare against. On an independently hand-scaled test year, our first-phase model gets a foF2 mean absolute error of 0.117 MHz; NICT's own autoscaler gets 0.264 MHz. Private until it's finished.

I also build Paperlane, a course marketplace for O and A Level students, with NestJS, Next.js, Prisma and PostgreSQL. I've merged 60+ pull requests there, covering auth, course review, enrolment, payments and deployment. Also private.
